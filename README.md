# A/B测试：Cookie Cats 关卡难度对留存影响

## 项目简介
针对游戏 Cookie Cats 的关卡难度调整（gate_30 → gate_40），基于 9万+ 玩家数据完成完整的 A/B 测试分析。

## 业务问题
将关卡障碍从第30关推迟至第40关，能否提升玩家留存与活跃度？

## 核心结论
推迟关卡对短期活跃无显著影响，但**7日留存率显著下降 0.82 个百分点**（p = 0.0016）。建议保留原版 gate_30 设置。

- 统计方法：卡方检验、独立样本t检验、缩尾处理（Winsorize）
